# Quick Guide: Host Privacy Policy on GitHub Pages

## 💡 Recommendation: Create a Separate Repository

**Why?** Cleaner URLs, better security, more professional. See `PRIVACY_POLICY_HOSTING_OPTIONS.md` for details.

## 🚀 Fastest Method (5 minutes)

### Step 1: Create GitHub Account (if needed)
- Go to: https://github.com/signup
- Sign up (free)

### Step 2: Create Repository

1. Go to: https://github.com/new
2. **Repository name:** `fraudulens-policy` (recommended) or `fraudulens-pages`
3. **Description:** Privacy Policy and Data Deletion for FrauduLens App
4. **Visibility:** ✅ **Public** (required for free GitHub Pages)
5. Click **Create repository**

**💡 Tip:** Using a separate repo keeps your code private and gives cleaner URLs!

### Step 3: Upload Files

1. In your new repository, click **Add file** → **Upload files**

2. **Drag and drop these files:**
   - `privacy-policy-template.html`
   - `data-deletion.html`

3. Click **Commit changes**

### Step 4: Enable GitHub Pages

1. In your repository, click **Settings** (top menu)

2. Scroll down to **Pages** (left sidebar)

3. Under **Source:**
   - Select: **Deploy from a branch**
   - **Branch:** `main` (or `master`)
   - **Folder:** `/ (root)`
   - Click **Save**

4. **Wait 1-2 minutes** for GitHub to deploy

### Step 5: Get Your URLs

Your pages will be available at:

- **Privacy Policy:**
  ```
  https://yourusername.github.io/fraudulens-pages/privacy-policy-template.html
  ```
  (Replace `yourusername` with your GitHub username)

- **Data Deletion:**
  ```
  https://yourusername.github.io/fraudulens-pages/data-deletion.html
  ```

### Step 6: Rename for Cleaner URLs (Optional)

1. In your repository, click on `privacy-policy-template.html`
2. Click the **pencil icon** (Edit)
3. Click **Rename** button
4. Rename to: `privacy-policy.html`
5. Click **Commit changes**

Now your URL will be:
```
https://yourusername.github.io/fraudulens-policy/privacy-policy.html
```

---

## ✅ Done!

Copy these URLs and add them to your Facebook App:
- Privacy Policy URL
- Data Deletion URL

## 🔄 Update Files Later

To update your privacy policy:
1. Go to your repository
2. Click on the file
3. Click **Edit** (pencil icon)
4. Make changes
5. Click **Commit changes**
6. Changes go live immediately!
